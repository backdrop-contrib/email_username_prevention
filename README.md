Email Username Prevention
==========================

This module prevents anyone from being able to register using an email address
in the username field, accidentally or otherwise. It also prevents existing
user accounts from having their usernames changed to be email address.

A validation error is thrown when an email is provided.


Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://backdropcms.org/guide/modules.

- This module has no settings.
